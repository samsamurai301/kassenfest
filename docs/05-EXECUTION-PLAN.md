## 1. Strategy in five rules

1. **Spike the two unknowns first** (Wed): Can Muse Spark read our forms (incl. handwriting + the visit grid)? Does SAM 3.1 find signatures/stamps on forms? Every later design choice branches on these answers.
2. **Contract first, then parallel.** Wednesday freezes the shared Pydantic schemas (documents, ground truth, findings). From Thursday, three independent tracks — synth, rules, web — run as parallel Claude sessions in separate worktrees; you review and merge.
3. **Walking skeleton by Saturday night**: upload demo folder → 🟢🟠🔴 board → click finding → evidence highlighted on the scan. Everything after that is enrichment. If the skeleton isn't there Saturday night, cut per §6.
4. **Demo-driven data.** Build the 5 hero patients early (Sat) and develop against them; eval sets are a second seed of the same generator.
5. **Every model call is cached and costed from day one** (record/replay). Deterministic demo, cheap re-runs, offline-safe recording.

## 2. Stack (replaces `01` §2 for the hackathon)

**Decision: Python backend + React frontend, zero infrastructure.** You said "use whatever is better" — this is better here because synth generation, image work, SAM mask decoding and eval are Python anyway; putting the API, pipeline and rules engine in the same language means **one schema source** and the eval harness calls the real pipeline in-process.

| Layer | Choice | Why (vs. `01`) |
|---|---|---|
| API + pipeline | **FastAPI + Pydantic v2**, asyncio | Pydantic models → JSON Schema for Muse Spark structured output **and** OpenAPI for the web client. One source of truth. |
| DB | **SQLite** via SQLModel (JSON columns) | Single-user demo; reset = copy a file. Postgres/Prisma adds nothing for the demo. |
| Jobs | **In-process async pipeline** + SSE progress, `asyncio.Semaphore` for model concurrency | Replaces BullMQ + Redis. 3,000 RPM limit is irrelevant at our volume. |
| Files | **Local disk**, content-addressed by sha256 (`var/blobs/`) | Replaces MinIO. |
| Models | `openai` Python SDK, `base_url=https://api.meta.ai/v1`; `muse-spark-1.3`, `sam-3.1`; `meta_sam_parser` | Client asserts model IDs never end in `-contributor`. |
| Doc rendering (synth) | **Jinja HTML/CSS → Playwright (Chromium) screenshot** | Ground-truth bboxes for free: `getBoundingClientRect()` on every `[data-field]` element. Handwriting via web fonts, signatures/stamps as inline SVG. |
| Degradation | OpenCV + numpy (geometry ourselves, so GT boxes are transformed exactly); Augraphy only for non-geometric ink/paper effects | Keeps GT valid under perspective warp. |
| Calendar | Python `holidays` (`Germany(subdiv="BY")`), municipality flag for Mariä Himmelfahrt | Verified by the boundary tests in `02` §8. |
| Web | **React + Vite + TS + Tailwind + shadcn/ui + TanStack Query**, types via `openapi-typescript` | Evidence viewer = `<img>` + SVG overlay (no canvas lib). |
| UI language | **English UI, German domain nouns** (Verordnung, Leistungsnachweis), findings show **DE + EN** text | Replaces the i18n toggle (`SET-08`); judges read English, users see the German. |
| Tooling | `uv` (Python 3.12), `ruff`, `pytest`; `pnpm`; one `Makefile` (`dev`, `synth`, `demo`, `eval`, `test`) | No Docker needed to run. Dockerfile only if the rules require a hosted URL. |

### 2.2 Core contracts (freeze on Wednesday)

- **`Field[T]`** — every extracted value: `{value: T | null, status: present | empty | unreadable, confidence: 0–1, page: int, bbox: [x0,y0,x1,y1] | null}`. The `empty` vs `unreadable` split is what lets rules say "signature missing" vs "send to human review" (`EXT-04`).
- **Ground truth** — format from `03` §4.4, generated by `synth`, never seen by the pipeline.
- **`Finding`** — `rule_id, rule_version, severity (block|warn|info), claim_line_ids[], message_de, message_en, source, evidence[]`; `Evidence = {document_id, page, field_key, bbox, mask_ref?}`. No evidence → can't block (ADR-3).
- **`Objection`** (auditor) — `code (Kasse code | FACT | INFO), claim_line_ids[], document_id?, page?, field_key?, statement` → resolver adds `verdict (upheld|dismissed), reason`.
- Muse Spark structured output: no recursive schemas, depth ≤ 10. Pydantic emits `$defs/$ref` — **spike S1 checks whether refs are accepted; if not, inline them** with a small dereference helper.

### 2.3 Model-call layer (built tonight / Wednesday, used by everything)

- Cache key = sha256(model, prompt id + version, schema hash, image sha256s, params). Stored as JSON in `var/llm-cache/` (`data/cache/demo/` for the demo set).
- `LLM_MODE=live | record | replay`. Demo recording and judges' runs use `replay`.
- Every call logs tokens, cost (`$1.25 / $4.25 per 1M`, SAM `$2.50 / 1k images`), latency → `llm_calls` table → cost per doc in the eval report (`EVL-05`).
- `reasoning_effort`: `low` for classify, `medium` for extract, `high` for auditor.

### 4.2 Handwriting, signatures, stamps (all generated → exact ground truth)

- **Handwriting**: Google Fonts handwriting faces with full German glyphs (Caveat, Kalam, Patrick Hand, Indie Flower, Reenie Beanie, Gochi Hand, …; OFL). Per-glyph `<span>` jitter (baseline ±2 px, rotate ±3°, scale ±6 %), blue/black ink, occasional strike-through + overwrite (D17 hard case, Tier B). **Verify umlaut/ß coverage per font on Wednesday** and drop fonts that lack them. `test` uses fonts never used in `dev`.
- **Signatures**: procedural Bézier scribbles (3–6 strokes, variable stroke width, slant) as SVG; seeded per person so a nurse's Handzeichen is consistent.
- **Stamps**: SVG text block (practice name, LANR/BSNR, address), blue-violet, rotation ±8°, `feTurbulence` ink-gaps mask, multiply blend.
- **Watermark** on every page: "MUSTER – SYNTHETISCH – KEIN ECHTES DOKUMENT" (`DOC-SYNTHETIC`).
- **Optional real-handwriting boost** (30 min, Sunday): you print 6 blank forms from the generator, fill them by hand from the instruction cards, photograph with your phone → a 6-doc "real handwriting" split reported separately. Highest credibility per minute in the whole plan; skip only if Sunday is on fire.

### 4.3 Form layout strategy
Muster 12 is a fixed KBV layout; the Leistungsnachweis is **the provider's own form** (no official template, `03` §2). So knowing their layouts is realistic product behaviour, not cheating. That enables a fallback for evidence boxes: template coordinates mapped through the page's perspective transform (Tier B `ING-03`). Free-form letters (Genehmigung, Entlassbrief) rely on Muse Spark boxes + SAM.
